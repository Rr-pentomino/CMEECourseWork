# Week 2 - Biological Bootcamp

## Project Description
This repository contains the scripts and resources for the second week of the Biological Bootcamp module. This week, we focus on applying Python for biological data analysis. The scripts cover topics like sequence alignment, control flow in programming, debugging, loops, and dictionaries.

## Languages
- **Python 3.x** (Tested with Python 3.8+)

## Dependencies
- **Python** (Version 3.x or higher)
- No external dependencies are required. However, if you need to use any specific packages (e.g., for sequence alignment), make sure to install them via pip

## Project Structure
- `week2/code`: Contains all Python scripts used for this module.
  - `align_seqs.py`: Script for sequence alignment.
  - `boilerplate.py`: Template for common Python setup.
  - `cf_exercises1.py`: Some functions for practice in Python.
  - `control_flow.py`: Control flow examples with `if`, `else`, `while`, `for` loops.
  - `debugme.py`: Debugging exercise in Python.
  - `dictionary.py`: Dictionary usage and operations.
  - `lc1.py`, `lc2.py`: Example scripts for loops and conditionals.
  - `loops.py`: More practice with Python loops.
  - `myexamplescript.py`: Custom example script for the week.
  - `oaks_debugme.py`: Debugging exercise related to oak data.
  - `test_control_flow.py`: Tests for control flow exercises.
  - `tuple.py`: Example usage of tuples in Python.
  - `using_name.py`: Handling variables and names in Python.

- `week2/data`: Contains sample data files for analysis.
  - `JustOaksData.csv`: Example data file with oak tree information.
  - `seq1.txt`: Sequence data for alignment exercises.
  - `TestOaksData.csv`: Another dataset for oak-related exercises.

- `week2/results`: Directory for storing output files, analysis results, and generated data.

- `week2/sandbox`: A working directory for experiments.
  - Files for testing and experimenting with different Python techniques.
