# Week 1 - Biological Bootcamp

## Project Description
This repository contains the scripts and resources for the first week of the Biological Bootcamp module. 
The content includes various Bash scripts for file manipulation, data processing, and other utilities that are essential for biological computing.

## Languages
- Bash (Version 5.1)

## Dependencies
- **Bash** (Version 5.1)
- **ImageMagick** (for `magick` command, used for image manipulation)

To install ImageMagick, use the following command:
  - On macOS: `brew install imagemagick`
  - On Ubuntu: `sudo apt-get install imagemagick`

## Project Structure
- `week1/code`: Contains all the Bash scripts used for this module.
- `boilerplate.sh`: A template for common shell script setup.
- `ConcatenateTe.sh`: Script for concatenating text files.
- `Countlines.sh`: Counts the number of lines in a file.
- `csvtospace.sh`: Converts CSV format to space-delimited format.
- `FirstExample.tex`: LaTeX example file.
- `MyExampleScript.sh`: Example shell script for basic operations.
- `tabtocsv.sh`: Converts tab-delimited files to CSV.
- `tiff2png.sh`: Converts TIFF images to PNG format.
- `unixprac1.txt`: Text file for Unix practice.
- `variables.sh`: Defines common variables for scripts.

- `week1/data`: Contains sample data files for analysis.
- `fasta`: Directory containing FASTA files.
- `Temperatures`: Data related to temperature readings.
- `spawnannxs.txt`: Text file with spawning data.

- `week1/results`: Directory for storing output files, analysis results, and generated data.


- `week1/sandbox`: A working directory for experiments.
- `testfind`, `testwild`: Example test files and directories.
- `mergedfiles.sh`: Script for merging files.
- `pythonEXP.txt`: Text file related to Python experiment.
